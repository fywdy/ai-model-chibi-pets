# 8 Chibi AI-Mascot Pets for the ChatGPT App

Eight tiny chibi characters, one per AI brand, made into **desktop pets you can use in the ChatGPT app**.
They sit in your window while you chat: running when work is happening, blinking when they wait for you,
slumping when something fails.

- **8 packs**, each with 9 animation states + 16 look directions (24 atlases, two size layouts)
- Art is generated by AI image models, then checked and repaired by hand, cell by cell
- **Community fan art**: not affiliated with, endorsed by, or sponsored by any brand — see [`NOTICE.md`](NOTICE.md)

> **中文说明**: see [`README.md`](README.md)

## 2. How to install

⚠️ **One thing to get right: there are two layouts, and using the wrong one misaligns the frames** ✗

| Layout | Size | For | Folder |
|---|---|---|---|
| **v2 · 11 rows** | 1536 × 2288 | **ChatGPT desktop app** (macOS / Windows) | `dist/codex-native/<id>/` |
| **v1 · 9 rows** | 1536 × 1872 | **ChatGPT web pet slot**, v1-only clients | `dist/codex-standard-9row/<id>/` |

### ⓪ macOS · desktop app: one line (paste into Terminal)

```bash
V=v1.0.0; SHA=5868c80d48e505f0bb50b5b222d0523c7a169d2cdbb167be1590333a1aa5a9ca
d="${TMPDIR:-/tmp}/pets-install"; mkdir -p "$d" && cd "$d" \
 && curl -fL -C - --retry 3 --retry-all-errors -o pets.tar.gz \
    "https://gh-proxy.com/https://github.com/fywdy/chatgpt-chibi-pets/releases/download/$V/codex-pets-install-$V.tar.gz" \
 && echo "$SHA  pets.tar.gz" | shasum -a 256 -c - \
 && tar xzf pets.tar.gz && bash "codex-pets-install-$V/dist/install-codex.sh" native
```

It **verifies the download's SHA-256 first** (if the digest doesn't match it stops and runs nothing ✗) →
unpacks → installs all 8 packs into `~/.codex/pets/`, **backing up anything it overwrites** →
then restart the app → **Settings → Pets → Refresh** ✓

> Pinned release tag + `gh-proxy` mirror ✓ the same digest is committed at `dist/SHA256SUMS` ✓ compare it yourself ✓
> Slow network? **Run the same line again** — `-C -` resumes ✓ add `--noproxy '*'` if a local proxy makes the mirror slower ✓
> Install elsewhere with `CODEX_HOME=/your/path` ✓ roll back by copying `~/.codex/pets_backup-<timestamp>/<id>/` back ✓

### ① Windows · desktop app: copy the folders (no command line)

1. Repo page → green **Code** → **Download ZIP** → unzip
2. Copy each `dist\codex-native\<id>\` folder (the whole folder) into:
   ```
   %USERPROFILE%\.codex\pets\<same id>\
   ```
   Create the `pets` folder if it doesn't exist ✓ copy all 8 folders if you want them all ✓
3. Open the **ChatGPT app → Settings → Pets → Refresh** → pick your pet ✓

> The folder name must match the `id` inside `pet.json` **exactly** ✓ and `pet.json` + `spritesheet.webp`
> must sit **side by side** ✓
> To remove one: just delete `%USERPROFILE%\.codex\pets\<id>\` ✓ (that folder only holds pet assets)

### ② ChatGPT web pet slot: **not a folder** ✗ (upload one image)

1. Open ChatGPT on the web → **Settings → Personalization → Pet**
2. **Upload pet** → choose this file (transparent background · exactly 1536 × 1872 · ≤ 20 MiB):
   ```
   dist/codex-standard-9row/<id>/spritesheet.webp
   ```
3. Save and select it ✓

> The web slot only accepts **1536 × 1872 (the 9-row layout)** ✓ don't upload the 11-row one ✗
> Pets installed in the desktop app's local `~/.codex/pets/` do **not** sync to the web ✓ install both if you want both ✓

### ③ Other clients

| Client | Use | How |
|---|---|---|
| **clawd-on-desk** | `dist/import-packages/<id>.zip` (if rejected, try `<id>-foldered.zip`) | Settings → Themes → Import pet zip |
| **CoPet** | same zip | Import pet pack |
| **Petdex** | `dist/codex-standard-9row/<id>/` or `codex-native` | Submit as-is, or `npx petdex install` |
| **Any image-capable client / player** | `dist/generic-assets/<id>/` | Contact sheets + `previews/*.gif|webp`; **prefer the WebP** ✓ (GIF has 1-bit transparency and hard edges ✗) |

> For the ChatGPT app always use `codex-native` (v2 ✓); `codex-standard-9row` is for the web slot and v1-only clients ✓ don't mix them up ✗

## 3. Troubleshooting

- **The pet doesn't show up** ⇒ ① folder name = the `id` in `pet.json`? ② both files side by side? ③ restart the app, then Refresh ✓
- **Garbled / misaligned frames** ⇒ wrong layout ✓ desktop = v2 (11 rows, 1536×2288) ✓ web = v1 (9 rows, 1536×1872) ✓
- **Hard or green edges** ⇒ that's the GIF preview ✓ use `previews/*.webp` ✓
- **Want to edit one** ⇒ just replace the two files inside `<id>/` ✓ keep `"spriteVersionNumber": 2` for v2 ✓
